- Exact BHFC brand colours and Adobe font styling
- Simplified customer-facing wording
- Menu categories:
  - Beer Battered Fish
  - Crumbed Fish
  - Grilled Fish
  - Burgers & Tacos
  - Chips
  - Snacks
- Drinks hidden
- No phone number
- Open daily · 11:30am–7:00pm
- Premium Australian beef tallow section
- Prepared fresh daily section
- Captain’s Pantry section
- Brunswick Heads drone section
- Embedded Google Map
- Get Directions link to the official Google Business Profile
- Existing Menu Manager integration retained

## Update the preview site

Extract the ZIP and upload all files into the root of the existing GitHub repository:

`BHFC2483/bhfc-website-stage1`

Replace existing files and commit. Render should redeploy automatically.

If required:

`Manual Deploy → Deploy latest commit`
