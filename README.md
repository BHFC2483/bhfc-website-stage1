# BHFC Digital Menu V13.2.4

GitHub-ready update built from the live V13.2.3 project.

## Changes

- Replaced the Main Menu Sauce tile with the latest supplied artwork.
- Added Cocktail Sauce through the updated artwork.
- Removed the old standalone **Add Chips** section from Main Menu column 1.
- Burger-section Add Chips remains controlled through Menu Manager/Square as a burger item.
- Retained all V13.2.3 fixes:
  - `wild caught` remains inline with fish names.
  - Main Menu footer remains anchored at the bottom.
  - Main Menu and Snacks & More previews scale independently.
  - Square syncing, mappings and persistent storage remain unchanged.

## Routes

- `/main` — Main Menu
- `/snacks` — Snacks & More
- `/admin` — Menu Manager

Keep the Render persistent disk mounted at `/var/data`.
