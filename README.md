# BHFC Website Preview — Stage 1.5

Preserves the existing desktop homepage design. Updates: transparent header logo, TV menu order, Beer Battered Fish heading, approved tallow copy, supplied Captain’s Pantry video, and a server-side Google service layer for hours, open/closed status, rating, reviews, address and directions. Popular Times is not used.

Render environment variables required: `GOOGLE_PLACES_API_KEY` and `GOOGLE_PLACE_ID`.
